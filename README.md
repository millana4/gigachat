# GigaChat Frontend

Чат-интерфейс для GigaChat на React + TypeScript.

## Демо

🔗 [https://millana4.github.io/gigachat](https://millana4.github.io/gigachat)

## Стек технологий

- React 19
- TypeScript 4.9
- Zustand 5 (стейт-менеджмент)
- Styled Components 6 (стилизация)
- React Router DOM 7 (маршрутизация)
- Моковые ответы вместо API с чатом

## Запуск локально

```bash
git clone https://github.com/millana4/gigachat.git
cd gigachat
npm install
npm start
